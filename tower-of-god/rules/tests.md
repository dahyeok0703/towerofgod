# 시험 판정 규칙 (Tests) — GM 운영 지침

> GM이 각 시험 type을 **어떻게 운영하는가**를 정한다.
> 결과가 걸린 수치 판정은 **직접 지어내지 않고 `engine/resolve.py`** 로 처리한다(4단계 구현 예정).
> 그 전까지 수치 판정 구간에 도달하면 "엔진 구현 후 진행"이라 알리고 임의 결과를 내지 않는다.
> 시험 데이터는 `data/floors.json`, 스탯/스킬은 `rules/progression.md`·`data/skills.json`.

---

## 0. 모든 시험의 공통 절차

1. **제시:** 시험관 등장 → 시험 type·설명·**통과조건**·보상·위험을 명확히 고지한다.
2. **입력:** 플레이어의 행동/선택/자유 입력을 받는다.
3. **판정:** 관련 스탯·스킬·상황 보정을 엔진에 넘겨 결과를 받는다.
4. **결과:** 아래 4분기 중 하나로 귀결하고, **세이브에 즉시 반영**한다.
   - **대성공** — 통과 + 추가 보상(보너스 EXP/평판/아이템).
   - **성공(통과)** — 다음 층 개방 + 기본 보상.
   - **실패** — 미통과. 패널티 적용, 조건부 재도전 가능.
   - **대실패** — 심각한 패널티(중상/자원 대량 손실/평판 급락/동료 이탈/사망 가능).
5. **기록:** 결과를 `ranking`/`reputation`/진행 플래그에 남긴다.

> 통과조건의 **수치 임계값**은 floors.json의 `test.통과조건` 과 4단계 엔진이 함께 결정한다.

## 1. 시험 type별 운영

### 1) 전투시험 (`전투시험`)
- **운영:** 지정된 적/시험관과 교전. 턴제 전투로 진행.
- **판정:** 전투 결과(생존·적 처치·시간 제한)를 엔진으로 산출.
- **통과:** 목표 격파 또는 규정 턴 생존. **대실패:** HP 0 → 사망/탈락.

### 2) 생존시험 (`생존시험`)
- **운영:** 일정 턴/구간 동안 환경·연속 위협을 버틴다.
- **판정:** 매 턴 위협 판정(RES·VIT·회피). 자원·HP 관리가 핵심.
- **통과:** 규정 시간 생존. **대실패:** 자원 고갈 후 연쇄 피해로 탈진/사망.

### 3) 협동시험 (`협동시험`)
- **운영:** 팀 결성·역할 분담이 목적. NPC/동료와 호흡을 맞춘다.
- **판정:** 역할 적합도·신뢰(평판)·소통 선택의 결과를 종합.
- **통과:** 팀 목표 달성. **대실패:** 분열로 팀 와해, 동료 이탈·평판 하락.

### 4) 퍼즐/지력시험 (`지력시험`)
- **운영:** 수수께끼·장치·논리 과제. 자유 입력 중심.
- **판정:** 추론의 타당성 + WIL 보정. 오답 누적/시간 제한 존재 가능.
- **통과:** 정답/해법 도달. **대실패:** 함정 발동으로 피해 또는 경로 봉쇄.

### 5) 포지션별 시험 (`포지션시험`)
- **운영:** 플레이어 포지션의 특성을 시험(낚시꾼=전선 유지, 등대지기=관측 등).
- **판정:** 해당 포지션 주력 스탯·시작 능력 활용도를 평가.
- **통과:** 포지션 과제 달성. **대실패:** 역량 부족 노출, 패널티 + 재도전 제약.

### 6) 선택의 시험 (`선택시험`) — 도덕/배신
- **운영:** 옳고 그름·이득과 신의가 충돌하는 선택. **정답이 없을 수 있다.**
- **판정:** 선택의 결과를 세계 상태/평판/동료 관계로 환산(수치 우열보다 분기 중심).
- **결과:** "통과/실패"보다 **분기**로 처리. 배신은 단기 이득·장기 대가를 남긴다.
- ⚠️ 결과를 미화하지 않는다. 선택의 무게를 정직하게 보여준다.

### 7) 추격/회피시험 (`추격시험`)
- **운영:** 쫓기거나 쫓는 상황. 기동·은신·판단의 연속.
- **판정:** AGI·WIL·탐색꾼 계열 능력 보정. 매 구간 분기 선택.
- **통과:** 탈출/포획 성공. **대실패:** 포위·낙오로 중상 또는 포로 분기.

### 8) 은신/탐색시험 (`탐색시험`)
- **운영:** 들키지 않고 목표 지점/물건에 도달. 정찰·함정 회피.
- **판정:** 은신·감지 대결(AGI·WIL·정찰 능력). 발각 누적치 관리.
- **통과:** 무발각 도달. **대실패:** 발각 누적 초과로 전투 강제 + 불리한 시작.

### 9) 가디언 대결 (`수호자대결`) — 보스
- **운영:** 층의 가디언/시험관 본인과의 결전. 여러 페이즈.
- **판정:** 고난도 전투 + 기믹 대응. 팀·자원·준비도가 총동원된다.
- **통과:** 가디언 격파/굴복. **대실패:** 전멸 → 사망/대규모 손실.

> 거점층(시장·길드)에는 시험이 없다. `test`가 비어 있고, 휴식·보급·영입·정보 거래만 제공한다.

## 2. 재도전 규칙

| 시험 type | 재도전 | 비고 |
|------|------|------|
| 전투/생존/포지션/지력/추격/탐색 | **가능** | 단, 매 재도전마다 패널티 누적(자원·평판·난이도 상승) |
| 협동시험 | 제한적 | 동료가 이탈하면 재구성 필요, 평판이 낮으면 영입 난항 |
| 선택의 시험 | **불가** | 선택은 되돌릴 수 없다. 분기로 확정된다 |
| 가디언 대결 | 조건부 | 회복·재정비 후 재도전 가능하나, 사망 시 종료 |

- 재도전 시 직전 **대실패의 부상/손실은 회복되지 않은 채** 시작한다(봐주기 없음).
- 거점층에서 충분히 정비하지 않은 재도전은 더 큰 위험을 부른다.

---

## 3. 실패 패널티 (예시 분류)

- **부상:** HP 감소·상태이상(출혈/탈진/약화)으로 다음 구간까지 지속.
- **자원 손실:** 신수(SP)·돈·아이템 소실.
- **평판 하락:** 거점층 거래/영입/일부 분기 불이익.
- **동료 영향:** 신뢰 하락·이탈, 최악의 경우 적대로 전환.
- **경로 봉쇄:** 특정 길/숨겨진 층 진입 조건 상실.
- **사망/탈락:** 대실패의 극단. 세이브에 확정 반영하며 되돌리지 않는다.

> 모든 임계값·패널티 수치는 placeholder다. **4단계 `engine/resolve.py`** 에서 확정한다.
