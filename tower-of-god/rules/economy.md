# 경제 규칙 (Economy) — 화폐·아이템·거래

> 화폐·아이템 흐름과 거래 규칙을 정한다. 도구는 **`engine/inventory.py`**.
> 장비 보정은 **`engine/resolve.py`** 가 전투에 반영한다. 수치는 placeholder(엔진 조정).
> 아이템 데이터: `data/items.json`.

---

## 1. 화폐

- 단위는 **돈**(세이브의 `돈`). 시험 보상·전투 드랍·퀘스트·판매로 얻고, 구매·수리·서비스로 쓴다.
- **획득:** 시험 통과 보상, 적 처치 드랍, 거점 의뢰, 아이템 판매, 숨겨진 보관고.
- **소비:** 장비/소모품 구매, 정보 구매, 사사·서비스 비용.

---

## 2. 아이템 종류와 등급

| 종류 | 역할 |
|------|------|
| 무기 | 장착. 주력 스탯·명중 보정 |
| 방어구 | 장착. 체력·신수저항·피해감소 |
| 장신구 | 장착. 보조 스탯·자원 상한·특수 |
| 소모품 | 사용. HP/신수 회복, 상태이상 해제 |
| 재료 | 제작·강화 재료 |
| 특수 | 포켓 등 비전투 기능 |

- 등급: **일반 < 고급 < 희귀 < 전설.** 높을수록 보정이 크고 비싸며 드물다.

---

## 3. 장비와 전투 연동 (engine/resolve.py)

- 장비 슬롯(무기/방어구/장신구)의 **`스탯보정`** 은 전투용 **유효 스탯**에 더해진다
  (기본 스탯 자체는 보존 — 로드된 사본에만 적용).
- **`효과`** 중:
  - `최대HP`/`최대신수` → 자원 상한 가산.
  - `피해감소`(0~1) → 받는 피해 비율 경감(합산 상한 0.75).
  - `명중` → 명중률 가산.
- 따라서 **장비 착용 전후로 전투 결과(피해·명중·생존)가 달라진다.** (회귀 테스트로 검증)

---

## 4. 상점과 평판 가격 (거점층)

거점층(시장·길드)에서 **`buy`/`sell`** 로 거래한다. 가격은 **평판**(→ `rules/social.md`)의 영향을 받는다.

- **구매가 배수** = `clamp(1 − 명성×0.001 + 악명×0.0005, 0.7, 1.3)`
  - 명성이 높을수록 **할인**, 악명이 높을수록 **할증**.
- **판매가** = `가격 × 0.4 × 평판배수`.
- 악명이 매우 높으면 일반 상점은 거래를 꺼리지만 **암시장**이 열린다(고악명 전용, 설정).
- **비매품**(가격 0, 예: 포켓)은 구매 불가.

---

## 5. 드랍 확률 (등급별 가이드)

> 실제 드랍은 GM/전투 결과에 따르되, 아래 대략치를 기준으로 한다(placeholder).

| 등급 | 대략 드랍 비중 | 비고 |
|------|---------------|------|
| 일반 | 60% | 흔한 소모품·기초 장비·재료 |
| 고급 | 28% | 중간 시험·강적 |
| 희귀 | 10% | 강적·숨겨진 층 |
| 전설 | 2% | 가디언 처치·특수 분기 |

- 강한 적(높은 `권장전투력`)일수록 상위 등급 확률이 오른다.

---

## 6. 강화·제작 (선택 시스템 — 개념)

> 골격만 정의하고, 수치 공식은 후속 단계에서 확정한다.

- **강화:** `재료`(예: 신수 파편)+돈으로 장비의 보정치를 단계적으로 올린다.
  실패 확률·비용 증가의 위험을 둔다(고강화일수록 위험).
- **제작:** 상위 재료(희귀 합금·가디언 핵)로 고등급 장비를 만든다. 도면/사사 요구 가능.
- 강화/제작 결과도 `engine/inventory.py`·`resolve.py` 데이터 흐름을 따른다.

---

## 7. 특수 아이템 — "포켓" 등 (오리지널 설정)

- **포켓(Pocket):** 도전자 표준 지급 장치. **저장(아이템·기록) / 통신 / 지도·기록 / 간이 신수 운용**.
  분실·파손 시 통신·지도 기능이 제한된다. 비매품.
- **층 지도:** 특정 층의 지형·함정 정보를 연다(탐색시험 유리).
- **귀환 두루마리:** 최근 거점층으로 즉시 귀환(일회용).
- **소형 등대:** 자율 정찰·관측 보조(등대지기 시너지).
