# rules/ — 규칙 문서

스탯, 성장, 전투, 자원, 사망 등 게임 규칙을 마크다운으로 정의합니다.
규칙 충돌 시 우선순위: **CLAUDE.md > rules/ > world/ > data/** (현재 수치값은 `save/`가 최종).

## 예정 문서 (2단계)

- `stats.md` — 스탯과 파생 수치(HP 등)
- `progression.md` — 성장/레벨/층 진행 규칙
- `combat.md` — 전투 흐름과 판정 규칙(엔진 연동)
- `resources.md` — 신수 자원·돈 규칙
- `death.md` — 부상·사망·탈락 규칙

> 봐주기 없음: 실패·부상·죽음이 가능하다는 원칙을 규칙 수준에서 구체화합니다. (CLAUDE.md 철칙 ③)
