# 탑 (Tower) — 신의 탑 영감 텍스트 RPG

신의 탑 세계관의 **구조**(탑을 오르며 층마다 시험을 통과한다)에서 영감을 받아
**전부 오리지널로 창작**한 텍스트 RPG입니다.
Claude Code가 **게임 마스터(GM)** 가 되어 진행하고, 당신은 탑을 오르는 도전자가 됩니다.

> 원작의 대사·고유명사·스토리는 일절 복제하지 않습니다. 세계관의 "뼈대"만 빌렸습니다.

---

## 플레이 방법

1. 이 폴더(`tower-of-god/`)에서 **`claude`** 를 실행합니다.
2. 채팅창에 **`게임 시작`** 이라고 입력합니다.
3. GM(Claude)이 세이브를 확인합니다.
   - 세이브가 있으면 → **이어하기**
   - 세이브가 없으면 → **캐릭터 생성**부터 안내
4. 이후 GM이 제시하는 **선택지를 고르거나 자유롭게 행동을 입력**하며 탑을 오릅니다.

```
$ cd tower-of-god
$ claude
> 게임 시작
```

---

## 진행 방식

- 매 턴 GM은 다음 형식으로 응답합니다:
  - **[상황 묘사]** → **[선택지 또는 자유 입력]** → **[현재 상태 1줄]**
- 모든 수치는 `save/player.json` 과 `save/world_state.json` 에 저장됩니다 (유일한 진실).
- 전투·판정 결과는 (4단계부터) `engine/resolve.py` 엔진이 계산합니다. GM이 임의로 정하지 않습니다.
- **봐주기는 없습니다.** 실패·부상·죽음이 실제로 일어날 수 있습니다.

## 폴더 구조

```
tower-of-god/
├── CLAUDE.md        # GM 계약서 (GM이 따르는 최우선 규칙)
├── README.md        # 이 문서
├── engine/          # 결정론적 로직 (파이썬) — 판정/전투
├── world/           # 세계관 설정 (md)
├── data/            # 게임 데이터 (json)
├── rules/           # 규칙 문서 (md)
└── save/            # 세이브 파일 (player.json / world_state.json)
```

---

## 개발 단계

- **1단계 (현재)** — 프로젝트 골격 + GM 계약서 작성 ✅
- 2단계 — 세계관/규칙 문서 작성 (`world/`, `rules/`)
- 3단계 — 게임 데이터 정의 (`data/`)
- 4단계 — 판정 엔진 구현 (`engine/resolve.py`)
- 이후 — 본격 플레이 테스트
