# 탑 (The Tower) — 텍스트 RPG

신의 탑 세계관의 **구조**(탑을 오르며 층마다 시험을 통과한다)에서 영감을 받아
**전부 오리지널로 창작**한 텍스트 RPG입니다.
**Claude Code가 게임 마스터(GM)** 가 되어 진행하고, 당신은 탑을 오르는 도전자가 됩니다.

> 원작의 대사·고유명사·스토리는 옮기지 않습니다. 세계관의 "뼈대"만 빌렸습니다.

---

## 설치 / 준비

1. **Python 3** 가 필요합니다(엔진 구동용). 추가 라이브러리는 없습니다.
2. **Claude Code** 를 설치합니다. (설치 안내: 공식 문서 참고)
3. 이 저장소를 받습니다.
```bash
git clone <repo-url>
cd tower-of-god
```

## 시작하기

이 폴더에서 **`claude`** 를 실행하고, 채팅창에 **`게임 시작`** 이라고 입력하세요.

```bash
cd tower-of-god
claude
> 게임 시작
```

- **처음이면** GM이 캐릭터 생성을 안내합니다(이름 → 포지션 → 출신 → 스탯 배분).
- **이어서 한다면** GM이 "어디까지 왔는지" 요약하고 그 지점에서 이어집니다.

당신은 GM이 제시하는 **선택지를 고르거나 자유롭게 행동을 입력**하며 탑을 오릅니다.
예) `2번 선택` · `검을 뽑아 정면으로 돌격한다` · `쿤에게 말을 건다`

## 포지션 (직업)

| 포지션 | 한 줄 |
|------|------|
| 낚시꾼 | 근접 화력·전선 유지 |
| 창지기 | 원거리 견제·마무리 |
| 등대지기 | 정보·지휘·다목적 지원 |
| 파도잡이 | 회복·영역(방房) 통제 |
| 탐색꾼 | 정찰·기동·함정 |
| 애니마 | 사역수 운용 *(특수 혈통 제한)* |

> **이레귤러**(고위험 고성장) 출신도 고를 수 있습니다 — 빠른 성장의 대가로 더 험한 길을 갑니다.

---

## 기본 플레이 (무엇을 입력하나)

GM에게 **자연어로** 말하면 됩니다. 자주 쓰는 행동:

- **이동/탐험** — "다음 층으로 간다", "주변을 살핀다" → GM이 이벤트·시험을 제시
- **전투** — "공격한다 / 〇〇 스킬을 쓴다 / 방어한다 / 도망친다" → GM이 엔진으로 판정
- **상태 확인** — "내 상태 / 인벤토리 / 스킬 / 랭킹을 보여줘"
- **상점(거점층)** — "회복약을 산다 / 사슬 갑주를 판다 / 장비를 착용한다"
- **대화/관계** — "〇〇에게 말을 건다 / 동료로 영입한다"
- **저장/불러오기** — "저장해줘 / 마지막 백업으로 되돌려줘"

> 모든 수치는 자동으로 `save/` 에 기록됩니다. 따로 관리할 필요는 없습니다.

## 규칙 한눈에

- **세이브가 진실:** 스탯·HP·돈·진행은 모두 `save/player.json`·`save/world_state.json` 에 저장됩니다.
- **판정은 엔진이:** 전투·확률은 `engine/` 의 결정론적 엔진이 계산합니다(GM이 임의로 정하지 않음).
- **봐주기 없음:** 실패·부상·**죽음**이 실제로 일어납니다. 단 **불공정한 즉사는 없습니다** —
  위험은 미리 알려주고, 빠져나갈 길이 최소 하나는 있습니다.
- **선택은 남습니다:** 배신·동맹·죽음 같은 분기는 되돌릴 수 없고 이후 이야기에 반영됩니다.
- **치트는 안 됩니다:** "스탯 올려줘" 같은 규칙 밖 요청은 받아들여지지 않습니다.
  정상 경로(시험·전투·퀘스트·거래)로 성장하세요.

## 팁

- **포지션 시너지를 노리세요.** 동료를 영입하면 전투에서 AI로 함께 싸웁니다(치유/딜 분담).
- **거점층(시장·길드)** 에서 충분히 정비하고 오르세요. 무리한 강행은 정직하게 응징당합니다.
- **신수(SP) 관리**가 핵심입니다. 강한 스킬은 소모가 큽니다. 회복약·정수병을 챙기세요.
- **장비를 갖추면 전투가 확 달라집니다.** 무기는 피해를, 방어구는 생존을 올립니다.
- **갈림길·숨겨진 층** 은 위험하지만 보상이 큽니다. 평판/관계가 새 길을 엽니다.
- **강한 랭커와는 정면승부하지 마세요.** 도주·교섭·성장으로 때를 기다리는 것도 실력입니다.
- **자주 저장**하세요. 손상·실수는 백업으로 되돌릴 수 있습니다.

## 폴더 구조

```
tower-of-god/
├── CLAUDE.md     # GM이 따르는 통합 규약
├── README.md     # 이 문서(플레이어용)
├── engine/       # 결정론적 엔진(파이썬): 판정·성장·아이템·관계·랭킹·퀘스트·세이브
├── world/        # 세계관 설정(신수·포지션·탑)
├── data/         # 게임 데이터(스킬·적·층·아이템·NPC·세력·랭커·퀘스트·이벤트)
├── rules/        # 규칙 문서(성장·시험·관계·경제·스토리)
└── save/         # 세이브(player.json·world_state.json) — 예시 파일 포함
```
