# engine/ — 결정론적 로직

전투·판정·확률 계산을 담당하는 **파이썬** 코드가 들어갑니다.

GM(Claude)은 결과가 걸린 행동을 **직접 계산하지 않고** 이곳의 함수를 호출해
반환값을 그대로 사용합니다. (CLAUDE.md 철칙 ② 참고)

## 예정 파일

- `resolve.py` — 핵심 판정 함수. **4단계에서 구현 예정.**
  - 입력: 행동/스탯/난이도 등
  - 출력: 성패, 데미지, 변경된 수치 등 결정론적 결과

> 아직 비어 있는 단계입니다. 판정이 필요한 장면에서는 엔진 구현 전까지 결과를 만들지 않습니다.
