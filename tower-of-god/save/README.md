# save/ — 세이브 파일 (유일한 진실)

GM은 매 턴 시작 시 이곳을 **읽고**, 턴 종료 시 변경분을 **저장**합니다.
여기 적힌 수치가 게임의 **유일한 진실(Single Source of Truth)** 입니다. (CLAUDE.md 철칙 ①)

## 파일

- `player.json` — 플레이어 상태(스탯/HP/신수/돈/층/랭킹/인벤토리/동료/진행)
- `world_state.json` — 세계 상태(플래그/이벤트/NPC 상태/시간)

> 두 파일은 **첫 캐릭터 생성 시 생성**됩니다.
> 세이브가 없으면 GM이 캐릭터 생성으로 안내합니다. (CLAUDE.md §3)
>
> 백업/임시/자동 세이브(`*.bak`, `*.tmp`, `autosave_*.json`)는 git에서 추적하지 않습니다.
